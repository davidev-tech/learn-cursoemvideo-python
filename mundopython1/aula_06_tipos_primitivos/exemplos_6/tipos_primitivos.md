# Tipos de Dados em Python

## `int`
- **Descrição:** números inteiros.
- **Exemplos:** `4`, `-5`, `367`, `7500`

## `float`
- **Descrição:** números quebrados / decimais.
- **Exemplos:** `4.0`, `-0.063`, `28.77`, `-27.36`

## `bool`
- **Descrição:** valores lógicos: **Verdadeiro** ou **Falso**.
- **Exemplos:** `True`, `False`

## `str`
- **Descrição:** Strings, ou seja, textos.
- **Exemplos:** `'Davi'`, `'22'`, `'4.0'`

---

## Tabela-resumo

| Tipo   | Significado                         | Exemplos                          |
|--------|-------------------------------------|-----------------------------------|
| `int`  | Números inteiros                    | `4`, `-5`, `367`, `7500`          |
| `float`| Números quebrados / decimais        | `4.0`, `-0.063`, `28.77`, `-27.36`|
| `bool` | Valores lógicos: Verdadeiro/Falso   | `True`, `False`                   |
| `str`  | Strings / textos                    | `'Davi'`, `'22'`, `'4.0'`         |

---

## Observações importantes

- Em Python, `True` e `False` começam com letra maiúscula.
- Valores entre aspas são considerados `str`, mesmo que pareçam números.
  - Exemplo: `'22'` é texto, não número inteiro.
  - Exemplo: `'4.0'` é texto, não número decimal.
- O separador decimal em Python é o ponto (`.`), não a vírgula.
